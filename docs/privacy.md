# Privacy Policy: yt-upload-cli

Last updated: October 21, 2026.

## Data accessed

yt-upload-cli asks for access to the user's YouTube account (scopes `youtube.upload` and `youtube`) only to upload videos, set thumbnails, add videos to playlists and show the name of the authorized channel.

## Use and storage

OAuth tokens (one per channel the user authorizes) are stored only on the user's own computer. yt-upload-cli has no servers: no data is sent to the developers, sold, shared with third parties or used for advertising. Videos and their metadata are sent only to YouTube, when the user runs an upload.

## Google API data

yt-upload-cli's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. By using it you also agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Removing an account with `yt-upload accounts remove <name>` (or deleting its folder) also removes its stored token.
