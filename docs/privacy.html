Privacy Policy: yt-upload-cli

Last updated: October 21, 2026.

Data accessed

yt-upload-cli asks for access to the user's YouTube account (scopes youtube.upload and youtube) only to upload videos, set thumbnails, add videos to playlists and show the name of the authorized channel.

Use and storage

The OAuth token is stored only on the user's own computer. yt-upload-cli has no servers: no data is sent to the developers, sold, shared with third parties or used for advertising. Videos and their metadata are sent only to YouTube, when the user runs an upload.

Google API data

yt-upload-cli's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using it you also agree to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token.json file also removes the stored token.

Contact

Open an issue at github.com/rsporteman/yt-upload-cli/issues.
