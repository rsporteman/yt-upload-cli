# yt-upload-cli

An open source command-line tool that uploads videos to the user's own YouTube channel using the YouTube Data API v3.

```
yt-upload upload video.mp4 --title "My video"
```

It runs entirely on the user's computer. OAuth tokens are stored locally and are sent only to Google.
